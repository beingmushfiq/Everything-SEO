## 1. Measurement Methodology

In strict compliance with our open-source integrity standards, this repository:
1. **Never fabricates engagement**: No fake stars, artificial forks, or paid promotion traffic.
2. **Relies on native GitHub Insights**: Tracks authentic developer interest via repository views, unique visitors, git clones, and referring domains.
3. **Documents baseline state**: Records Day 1 baseline as the reference point for evaluating growth over 14, 30, and 90-day intervals.
