## 1. Visual Identity & Brand Philosophy

The visual presentation of **Everything SEO** must communicate **deterministic engineering rigor, epistemic authority, and architectural precision**. It must immediately stand out from generic digital marketing graphics, avoid cartoonish clip art, and establish credibility with software engineers, technical SEO architects, and AI developers.

### Color Palette
- **Canvas Background**: Deep Onyx / Obsidian `#0B0F19` (Solid, high-contrast technical dark theme).
- **Primary Text & Headings**: Crisp White `#FFFFFF` and Slate Platinum `#E2E8F0`.
- **Primary Accent / Brand Color**: Electric Cyan / Terminal Blue `#38BDF8` (Represents deterministic telemetry, network routing, and data precision).
- **Secondary Accent**: Emerald Glow `#34D399` (Represents verified checks, 100% pass status, and growth).
- **Subtle Grid / Border Accents**: Deep Slate `#1E293B` (Subtle 1px architectural grid lines or terminal wireframe border).

### Typographic Specifications
1. **Primary Title**:
   - Text: `Everything SEO`
   - Font: Inter, SF Pro Display, or JetBrains Mono (Semi-bold / 700 weight).
   - Size: 64–72 pt. Color: `#FFFFFF`.
2. **Subtitle / Core Value Proposition**:
   - Text: `A Deterministic Operational Skill Library for AI Agents & SEO Leads`
   - Font: Inter or Roboto Flex (Regular / 400 weight).
   - Size: 26–28 pt. Color: `#94A3B8`.
3. **Capability Pill Bar**:
   - Text: `11 Core Disciplines  •  55 Operational Skills  •  100% Offline CI`

4. **Verbs / Workflow Footer**:
