Autonomous AI coding and research agents should interact with this library following these operating principles:

1. **Trigger Identification**: Check the frontmatter `description` and section **B. Trigger Conditions** of the candidate skill to confirm relevance to the user's request.
2. **Deterministic Execution**: Execute workflows step-by-step as defined in section **G. Operational Workflow**.
3. **Evidence Distinction**: Adhere strictly to section **F. Core Concepts** to distinguish verified Google documentation from third-party metrics and experimental hypotheses.
4. **Handoff Protocols**: Use section **O. Related Skills** to hand off intermediate artifacts to downstream skills (e.g. passing discovered queries from Keyword Discovery to SERP Analysis).
5. **Quality Verification**: Execute the checklist in section **K. Quality Assurance** before declaring any task complete.
