# 💬 Support & Help Guide

> **Maintained by:** DevCenterPoint  
> **Project:** Everything SEO

Thank you for using **Everything SEO**! Here is how to get help, report issues, and participate in our open-source community.

---

## 🔍 Before Reaching Out

To find answers quickly:
1. **Search the Skills**: Check [`SEO/SKILL_INDEX.md`](SEO/SKILL_INDEX.md) to locate the exact operational skill for your objective.
2. **Review the FAQ**: Read [`FAQ.md`](FAQ.md) for answers to common questions about usage, AI agents, and tooling.
3. **Inspect Examples**: Review practical end-to-end case studies in the [`examples/`](examples/) directory.
4. **Use Templates**: Explore reusable audit reports and work orders in the [`templates/`](templates/) directory.

---

## 🐛 Reporting Bugs & Broken Instructions

If you discover a broken link, invalid YAML frontmatter, an outdated search engine documentation link, or an error in a procedural script:

1. Check our [GitHub Issues](https://github.com/DevCenterPoint/Everything-SEO/issues) to see if the issue has already been reported.
2. If not, open a new issue using the **[Bug Report Form](.github/ISSUE_TEMPLATE/bug_report.yml)**.
3. Include:
   - File path of the skill (e.g., `SEO/Technical SEO/Crawling/SKILL.md`).
   - The specific step, command, or link that failed.
   - Expected vs. actual behavior.
   - Operating system and Python version (if reporting a script defect).

---

## 💡 Requesting a New Skill or Feature

Have a specialized search capability you'd like to see included (e.g., AI video search, regional engine protocols)?
- Open an issue using the **[Skill Request Form](.github/ISSUE_TEMPLATE/skill_request.yml)**.
- Describe the operational problem, required inputs, standard deliverable, and primary reference documentation.

---

## 🛡️ Security Vulnerabilities

If you discover a security vulnerability or credential leak in the repository, please follow our [Security Policy](SECURITY.md) and do **not** open a public issue.

---

## 🤝 Community Philosophy

This is a community-driven project maintained under open-source governance. We encourage civil, constructive dialogue, and all interactions must adhere to our [Code of Conduct](CODE_OF_CONDUCT.md).
