## 2. Project Summaries

### 2.1 Short Summary (For Directories, Social Bios & Curated Lists)
Everything SEO is an interconnected open-source capability library comprising 55 deterministic operational skills across 11 core search disciplines. Built strictly to the Agent Skills Open Specification v1.0, it delivers actionable, machine-readable instruction manuals (`SKILL.md`) equipped with concrete CLI commands, server configuration snippets, and diagnostic decision trees. It empowers autonomous AI coding agents (Antigravity, Claude Code, Cursor) and human technical SEOs to execute audits, optimize search visibility, and scale organic pipeline without superficial folklore or SaaS tool lock-in.

### 2.2 Detailed Project Description (For Launch Articles & README)
Search engine optimization has historically suffered from fragmented folklore, superficial checklists, and expensive tool subscriptions. Autonomous AI coding agents frequently fail at SEO tasks because standard web prompts lack operational boundaries, input prerequisites, diagnostic heuristics, and deliverable specifications.

**Everything SEO** bridges this divide by formalizing search engine optimization into an engineering discipline. Maintained by **DevCenterPoint**, the repository houses 55 self-contained, machine-actionable capability manuals organized into 11 core disciplines: Keyword Research, On-page SEO, Content Optimization, Technical SEO, Link Building, AI SEO, International SEO, Analytics, SEO Tools, SEO Wins, and Growth.

Each skill strictly adheres to a uniform 17-section ontology (Sections A through Q) with valid YAML frontmatter. Procedures are anchored in a strict **4-tier epistemic hierarchy**, drawing directly from official IETF RFCs (RFC 3986, RFC 9309, RFC 9110), W3C standards, Schema.org vocabularies, and official search engine documentation. The library operates 100% offline, requires zero paid APIs for validation, and provides free, open-source tool fallbacks for every workflow.

## 5. Compatibility & Limitations

### 5.1 Verified AI Agent Compatibility
- **Google Antigravity**: Fully supported. Can ingest individual skills or traverse the skill graph.
- **Claude Code (Anthropic)**: Fully supported via Agent Skills Open Specification standard.
- **Cursor / GitHub Copilot**: Supported as repository context and rules documentation.
- **OpenAI Swarm / Custom LLM Workers**: Supported via direct prompt context injection.

### 5.2 Technical & Operational Limitations
- **Instructions vs. Executable Daemon**: The library provides deterministic instructions, CLI snippets, and schemas; it does not run as a continuous background daemon crawler.
- **Algorithmic Opacity**: Search engines continuously alter machine learning weights. Where exact ranking mechanics are non-public, guidance is labeled as empirical inference (Tier 2) or practitioner proxy (Tier 3), never guaranteed fact.
